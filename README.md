# Kishan Sahu — Portfolio

Next.js 14 (App Router) · Tailwind CSS · Framer Motion · Geist font.
Live: https://portfolio-kishan-sigma.vercel.app/

## Edit your content
Everything (bio, skills, projects, experience, links) lives in **`src/data/site.js`**.
Project screenshots go in `public/images/projects/` (use ~1200px wide `.webp`).
Replace the resume at `public/Kishan_Sahu_Resume.pdf`.

## Run
```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```

## Deploy
- **Vercel (recommended):** import the repo, set `NEXT_PUBLIC_SITE_URL` to your final domain.
- **GitHub Pages / static host:** `NEXT_EXPORT=true npm run build` → upload `./out`.
